# Viral2Anime

A web app for creating and managing anime-styled content projects — start from trending ideas and produce anime-inspired versions. Built with ASP.NET Core MVC.

## Features

- Project creation workflow (`CreateController`)
- Project gallery and management (`ProjectsController`)
- User accounts and content organization

## Tech stack

- ASP.NET Core MVC (C#)
- Entity Framework Core + SQL Server
- Razor Views

## Getting started

```bash
dotnet restore
dotnet ef database update
dotnet run
